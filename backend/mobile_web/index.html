Appearance

Connect to your PC

Use a one-time owner invitation from anywhere, or connect on the same private network.

Install on Android or iPhone

Android: Tap Chrome menu → Install app or Add to Home Screen for a native standalone app.
iPhone/iPad: Tap Safari Share → Add to Home Screen.
Both give you a standalone phone app icon that connects to your PC backend anywhere in the world!

Secure connections

Internet access must use the owner's HTTPS tunnel. Never expose port 8000 directly on the router.
